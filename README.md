# Pixel Warriors website

Live at **https://pixelwarriors.in** (GitHub Pages, custom domain in `CNAME`).

- `index.html` – studio home with the list of games
- `swarm-survivor/` – Swarm Survivor game page
- `metro-sprint/` – Metro Sprint game page (images in `img/metro-sprint/`)
- `privacy.html` – privacy policy for all Pixel Warriors games
- `app-ads.txt` – AdMob seller file (must stay at the domain root)
